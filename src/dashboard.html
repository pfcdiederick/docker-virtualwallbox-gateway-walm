      Charger Profile

      The profile is the Modbus register list of the connected charger. Read the active profile or select a file, edit it below and write it to the gateway. It is checked before it is saved (the old one is kept as .bak) and takes effect after a restart of the gateway.

      Log in (gear button at the top right) to read, edit, write or restart.

      You are logged in with the default password: change it on Configuration > Login.

      Dashboard Login

      Stored on the controller in dashboard-login.toml (next to gateway.toml), the password only as a hash. Forgotten password: delete that file and restart the gateway (back to admin / wago). Use https://<controller>/walmgateway/ so the password is not sent in plain text.
